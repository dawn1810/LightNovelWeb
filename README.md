# Light Novel Web

> Website đọc và đăng tải truyện chữ (light novel), kèm trang quản lý người dùng và truyện.

Dự án nhóm. Người dùng đọc truyện, xem thông tin và đăng tải truyện; hệ thống có phần quản lý người dùng và quản lý nội dung truyện chữ.

## Tính năng

**Người đọc**
- Đọc truyện chữ theo chương
- Xem thông tin truyện
- Đăng tải truyện (hỗ trợ `.txt` và `.docx`)

**Quản trị**
- Quản lý người dùng
- Quản lý truyện và chương

## Công nghệ

- **JavaScript** (web app)
- Xử lý tải lên và chuyển đổi tài liệu truyện

## Chạy dự án

```bash
npm install
npm start
```
